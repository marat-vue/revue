# Как отлаживать Express API через `curl`, Postman и журналы?

> [!NOTE]
> Сначала воспроизведи запрос вне Vue. Затем проверь метод, адрес, заголовки, тело, код ответа и журнал сервера. Это быстро отделяет ошибку интерфейса от ошибки API.

## Вопрос

Как отлаживать Express API через `curl`, Postman, вкладку Network и журналы сервера?

## Проверка через `curl`

Получить список:

```bash
curl -i http://localhost:3000/api/users
```

Создать пользователя:

```bash
curl -i \
  -X POST http://localhost:3000/api/users \
  -H 'Content-Type: application/json' \
  -d '{"name":"Анна","email":"anna@example.com"}'
```

`-i` показывает код и заголовки ответа.

## Что проверить в Postman

- правильный HTTP-метод;
- точный адрес и порт;
- `Content-Type: application/json`;
- JSON без лишней запятой;
- cookie или заголовок авторизации;
- код ответа;
- тело ошибки;
- время запроса.

## Вкладка Network во Vue

В инструментах браузера сравни:

- Request URL;
- Request Method;
- Request Headers;
- Request Payload;
- Status Code;
- Response;
- запрос `OPTIONS`, если он был.

## Порядок поиска ошибки

```text
1. Доходит ли запрос до Express?
2. Совпадает ли маршрут?
3. Разобрано ли тело?
4. Проходит ли Zod?
5. Запускается ли запрос к базе?
6. Что вернула PostgreSQL?
7. Как ошибка преобразована в HTTP?
8. Как Vue обработал ответ?
```

## Полезный идентификатор

Если сервер возвращает `x-request-id`, запиши его вместе с сообщением об ошибке. По нему легче найти все записи одного запроса.

## Отладчик Node.js

```bash
node --inspect dist/server.js
```

В режиме `tsx` можно использовать настройки запуска VS Code и ставить точки останова прямо в TypeScript.

Не оставляй открытый порт отладчика доступным из внешней сети.

## Что важно помнить

- Сначала воспроизводят запрос без Vue — так видно, где ошибка: в интерфейсе или в API.
- Сверяют метод, адрес, `Content-Type`, тело и код ответа.
- Ошибка CORS видна только в браузере; `curl` и Postman её не покажут.
- Запрос в журнале находят по `x-request-id` из ответа.
- `node --inspect` позволяет ставить точки останова в обработчиках.

## Мини-шпаргалка

- Сначала повтори запрос через `curl` или Postman.
- Сверь метод, адрес, заголовки и тело.
- Посмотри Network и журнал Express.
- Ищи запрос по `x-request-id`.
- Отделяй ошибку Vue от ошибки API и базы.
