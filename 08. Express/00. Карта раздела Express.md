# Карта раздела Express

> [!NOTE]
> Этот раздел учит создавать небольшой, но правильно устроенный API на TypeScript: принять HTTP-запрос, проверить данные, обратиться к PostgreSQL через `pg` или Drizzle ORM и вернуть понятный ответ.

## Вопрос

Как изучать Express с нуля и в каком порядке проходить темы: от первого сервера до PostgreSQL, Drizzle, тестов и связи с Vue?

## Для кого этот раздел

Материал рассчитан на фронтендера, который знает JavaScript и TypeScript, но почти не работал с сервером.

После прохождения раздела ты сможешь:

- создать Express-приложение с нуля;
- написать REST API для Vue-приложения;
- понимать маршруты и промежуточные обработчики;
- проверять входные данные через Zod;
- подключиться к PostgreSQL через драйвер `pg`;
- безопасно выполнять SQL-запросы;
- описать таблицы и запросы через Drizzle ORM;
- создавать и применять миграции;
- разделить код на маршруты, обработчики, службы и работу с данными;
- объяснить основные решения на собеседовании.

## Основной пример раздела

Будем создавать API для пользователей и задач:

```text
Vue → HTTP → Express → проверка данных → служба → Drizzle → pg → PostgreSQL
                                                                    ↓
Vue ← JSON ← Express ← результат запроса ←──────────────────────────┘
```

Основные адреса:

```text
GET    /api/users
GET    /api/users/:id
POST   /api/users
PATCH  /api/users/:id
DELETE /api/users/:id
GET    /api/users/:id/tasks
```

## Что выбрать: `pg` или Drizzle

Это не взаимоисключающие инструменты:

```text
PostgreSQL ← pg ← Drizzle ORM ← код приложения
```

- `pg` открывает соединения и отправляет SQL в PostgreSQL;
- Drizzle строит типизированные запросы и использует `pg` как драйвер;
- SQL всё равно нужно понимать хотя бы на базовом уровне.

Сначала изучи `pg`, затем Drizzle. Так будет понятно, какую работу берёт на себя ORM.

## Версии и подход

Примеры рассчитаны на Express 5, современный Node.js, TypeScript, PostgreSQL, стабильную версию Drizzle ORM и драйвер `pg`. В проекте используются ES-модули и строгая проверка типов.

## Мини-шпаргалка

- Express принимает запрос и выбирает обработчик.
- Zod проверяет недоверенные данные.
- `pg` управляет соединениями и отправляет SQL.
- Drizzle помогает строить типизированные запросы.
- PostgreSQL хранит данные и обеспечивает ограничения.
- Хороший API возвращает правильные коды и единый формат ошибок.
