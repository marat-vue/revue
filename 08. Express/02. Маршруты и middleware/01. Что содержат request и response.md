# Что содержат `request` и `response`?

> [!NOTE]
> `request` описывает входящий HTTP-запрос, а `response` предоставляет методы для формирования ответа. Часто используются короткие имена `req` и `res`.

## Вопрос

Какие данные содержит объект `request` и какие методы есть у `response`? Почему на запрос отправляется только один ответ?

## Основные данные запроса

```ts
app.post("/api/users/:id", (request, response) => {
  console.log(request.method);
  console.log(request.path);
  console.log(request.params);
  console.log(request.query);
  console.log(request.body);
  console.log(request.headers.authorization);

  response.json({ ok: true });
});
```

| Свойство | Что содержит |
|---|---|
| `request.method` | HTTP-метод |
| `request.path` | Путь без строки запроса |
| `request.params` | Параметры пути |
| `request.query` | Параметры после `?` |
| `request.body` | Тело, разобранное промежуточным обработчиком |
| `request.headers` | Заголовки |
| `request.ip` | Адрес клиента с учётом настроек прокси |

## Основные методы ответа

```ts
response.status(201).json({ id: 42 });
```

| Метод | Назначение |
|---|---|
| `status(code)` | Установить код ответа |
| `json(value)` | Отправить JSON |
| `send(value)` | Отправить строку, буфер или другое значение |
| `set(name, value)` | Установить заголовок |
| `location(url)` | Установить заголовок `Location` |
| `redirect(url)` | Отправить перенаправление |
| `end()` | Завершить ответ без тела |

## Один ответ на один запрос

После отправки ответа функция должна завершиться:

```ts
app.get("/api/users/:id", (request, response) => {
  const user = undefined;

  if (!user) {
    response.status(404).json({ message: "Пользователь не найден" });
    return;
  }

  response.json(user);
});
```

Без `return` код может попытаться отправить второй ответ и вызвать ошибку:

```text
Cannot set headers after they are sent
```

## Данные запроса нельзя считать безопасными

Типы TypeScript не проверяют данные, которые пришли по сети. Клиент может прислать строку вместо числа, пропустить поле или отправить лишний объект.

```ts
// request.body имеет данные из внешнего мира.
const input = createUserSchema.parse(request.body);
```

## Что важно помнить

- `params`, `query`, `body` и заголовки приходят от клиента и не проверены — типы TypeScript их не защищают.
- `request.ip` зависит от настройки `trust proxy`, если приложение стоит за обратным прокси.
- После `response.json()` в ветке условия нужен `return`, иначе возможна ошибка `Cannot set headers after they are sent`.
- Короткие имена `req` и `res` — то же самое, это вопрос соглашения в команде.

## Мини-шпаргалка

- `request` содержит входные данные.
- `response` формирует HTTP-ответ.
- После `response.json()` или `response.send()` обычно нужен `return`.
- На один запрос отправляется только один ответ.
- `params`, `query`, `body` и заголовки нужно проверять.
