# Как делать `JOIN` и загружать связи в Drizzle?

> [!NOTE]
> `JOIN` объединяет строки связанных таблиц в одном SQL-запросе. Описание `relations()` позволяет получать вложенные объекты через API запросов Drizzle.

## Вопрос

Как делать `JOIN` в Drizzle и загружать связанные данные через `db.query`? Что такое проблема N + 1?

## Обычный `LEFT JOIN`

```ts
import { eq } from "drizzle-orm";

const rows = await db
  .select({
    taskId: tasks.id,
    title: tasks.title,
    userId: users.id,
    userName: users.name,
  })
  .from(tasks)
  .leftJoin(users, eq(tasks.userId, users.id));
```

При `LEFT JOIN` данные пользователя могут быть `null`, если связь необязательна и подходящей строки нет.

## `INNER JOIN`

```ts
const rows = await db
  .select()
  .from(tasks)
  .innerJoin(users, eq(tasks.userId, users.id));
```

Он возвращает только строки, для которых найдена запись с обеих сторон.

## Запрос через связи

Если `usersRelations` и `tasksRelations` описаны, а `schema` передана в `drizzle()`:

```ts
const user = await db.query.users.findFirst({
  where: eq(users.id, id),
  with: {
    tasks: true,
  },
});
```

Результат имеет вложенную структуру:

```ts
{
  id: 42,
  name: "Анна",
  tasks: [
    { id: 1, title: "Изучить Express" },
  ],
}
```

## Выбор столбцов связи

```ts
const user = await db.query.users.findFirst({
  where: eq(users.id, id),
  columns: {
    id: true,
    name: true,
    email: true,
  },
  with: {
    tasks: {
      columns: {
        id: true,
        title: true,
      },
    },
  },
});
```

## Проблема N + 1

```text
1 запрос списка пользователей
+ по 1 запросу задач для каждого пользователя
= N + 1 запрос
```

Для списка из ста пользователей получится 101 запрос. Загружай связанные данные общим `JOIN`, запросом связей или отдельным пакетным запросом.

## Связь и внешний ключ — разные вещи

- `.references()` создаёт ограничение PostgreSQL;
- `relations()` описывает связь для Drizzle;
- для надёжности обычно нужны оба уровня.

## Что важно помнить

- `INNER JOIN` теряет строки без пары, `LEFT JOIN` сохраняет их со значением `null`.
- `db.query.users.findMany({ with: { tasks: true } })` работает, только если схема и `relations()` переданы в `drizzle()`.
- Запрос в цикле для каждой строки списка — это N + 1: вместо одного запроса выполняется N + 1.
- `relations()` описывает связь для Drizzle, а целостность данных обеспечивает внешний ключ.

## Мини-шпаргалка

- `INNER JOIN` оставляет только совпавшие строки.
- `LEFT JOIN` сохраняет строки левой таблицы.
- `db.query` умеет возвращать вложенные связи.
- Передавай `schema` при создании Drizzle.
- Следи за проблемой N + 1.
