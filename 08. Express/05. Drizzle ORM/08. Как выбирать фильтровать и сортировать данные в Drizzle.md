# Как выбирать, фильтровать и сортировать данные в Drizzle?

> [!NOTE]
> `select()` явно описывает возвращаемые столбцы, `where()` задаёт условие, а `orderBy()`, `limit()` и `offset()` управляют списком.

## Вопрос

Как выбирать, фильтровать, сортировать и пагинировать данные в Drizzle?

## Все столбцы

```ts
const result = await db.select().from(users);
```

Тип результата выводится из схемы.

## Только нужные столбцы

```ts
const result = await db
  .select({
    id: users.id,
    name: users.name,
    email: users.email,
  })
  .from(users);
```

Не выбирай тяжёлые или секретные поля без необходимости.

## Один пользователь

```ts
import { eq } from "drizzle-orm";

const [user] = await db
  .select()
  .from(users)
  .where(eq(users.id, id))
  .limit(1);
```

Если строка не найдена, `user` будет `undefined`.

## Несколько условий

```ts
import { and, eq, ilike } from "drizzle-orm";

const result = await db
  .select()
  .from(users)
  .where(
    and(
      eq(users.isBlocked, false),
      ilike(users.name, `%${search}%`),
    ),
  );
```

Значение `search` передаётся параметром, а не вставляется в готовую SQL-строку.

## Сортировка и пагинация

```ts
import { desc } from "drizzle-orm";

const result = await db
  .select()
  .from(users)
  .orderBy(desc(users.createdAt))
  .limit(limit)
  .offset(offset);
```

## Общее количество

```ts
import { count } from "drizzle-orm";

const countRows = await db
  .select({ value: count() })
  .from(users);

const total = countRows[0]?.value ?? 0;
```

Проверка через `?.` нужна из-за строгих настроек TypeScript: компилятор не может заранее доказать, что массив содержит строку. Запрос с `count()` вернёт её, но безопасное значение по умолчанию делает это намерение явным.

## Условные фильтры

```ts
const conditions = [
  query.search ? ilike(users.name, `%${query.search}%`) : undefined,
  query.blocked !== undefined
    ? eq(users.isBlocked, query.blocked)
    : undefined,
];

const result = await db
  .select()
  .from(users)
  .where(and(...conditions));
```

## Что важно помнить

- `select()` без аргументов возвращает все столбцы — для ответа API лучше перечислить нужные.
- Операторы `eq`, `and`, `or`, `ilike`, `inArray` импортируются из `drizzle-orm`.
- Результат всегда массив: для одной записи используют `const [user] = await ...` и `.limit(1)`.
- `undefined` внутри `and()` игнорируется — так удобно строить необязательные фильтры.
- Общее количество для пагинации считается отдельным запросом `count()` с теми же условиями.

## Мини-шпаргалка

- `select().from(table)` читает строки.
- Частичный объект в `select` ограничивает столбцы.
- `eq`, `and`, `ilike` строят условия.
- `orderBy`, `limit`, `offset` управляют списком.
- Для одного результата массив удобно распаковать через `[value]`.
