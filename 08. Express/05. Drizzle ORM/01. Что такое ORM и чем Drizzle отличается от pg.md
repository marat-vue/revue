# Что такое ORM и чем Drizzle отличается от `pg`?

> [!NOTE]
> ORM связывает таблицы базы с объектами и типами программы. Drizzle остаётся близкой к SQL: ты явно выбираешь таблицу, условия, соединения и возвращаемые столбцы.

## Вопрос

Что такое ORM и чем Drizzle отличается от прямой работы через `pg`?

## Основная идея

ORM расшифровывается как **Object-Relational Mapping** — объектно-реляционное отображение.

## Один запрос на трёх уровнях

SQL:

```sql
SELECT id, name, email
FROM users
WHERE id = 42;
```

Через `pg`:

```ts
await pool.query(
  "SELECT id, name, email FROM users WHERE id = $1",
  [42],
);
```

Через Drizzle:

```ts
await db
  .select({
    id: users.id,
    name: users.name,
    email: users.email,
  })
  .from(users)
  .where(eq(users.id, 42));
```

## Что даёт Drizzle

- названия таблиц и столбцов проверяются TypeScript;
- результат запроса получает выведенный тип;
- значения безопасно передаются как параметры;
- схема таблиц хранится рядом с кодом;
- Drizzle Kit создаёт SQL-миграции;
- запросы можно дополнять обычными SQL-фрагментами.

## Чего Drizzle не делает

- не запускает PostgreSQL;
- не проверяет HTTP-тело вместо Zod;
- не создаёт индексы автоматически из догадок;
- не делает любой запрос быстрым;
- не заменяет понимание связей и транзакций;
- не применяет изменения схемы только из-за запуска Express.

## Drizzle и активная запись

Некоторые ORM возвращают объект с методами вроде `user.save()`. Drizzle обычно работает через явные запросы:

```ts
await db.update(users).set({ name: "Мария" }).where(eq(users.id, 42));
```

Это делает выполняемую операцию заметной в коде.

## Когда использовать сырой `pg`

- учебная работа с SQL;
- очень специфичный запрос;
- уже существующий проект на SQL;
- функция PostgreSQL, которую неудобно выразить построителем.

Drizzle позволяет выполнить и SQL-фрагмент, поэтому выбор не является окончательным.

## Что важно помнить

- Drizzle близок к SQL: запрос читается почти как SQL, но с типами TypeScript.
- ORM не заменяет базу данных, ограничения PostgreSQL и проверку входа через Zod.
- Drizzle не использует подход Active Record: строки — обычные объекты без методов сохранения.
- Сложный или специфичный для PostgreSQL запрос можно написать сырым SQL рядом с Drizzle.

## Мини-шпаргалка

- `pg` отправляет SQL и возвращает строки.
- Drizzle строит типизированный SQL поверх драйвера.
- ORM не является базой данных.
- Входные данные всё равно проверяются отдельно.
- SQL остаётся важным для производительности и отладки.
