# Как установить Drizzle и подключить `pg`?

> [!NOTE]
> Для PostgreSQL устанавливаются `drizzle-orm`, драйвер `pg` и средство миграций `drizzle-kit`. Drizzle можно подключить к уже созданному пулу.

## Вопрос

Как установить Drizzle ORM и подключить его к PostgreSQL через `pg`?

## Установка

```bash
npm install drizzle-orm pg
npm install --save-dev drizzle-kit @types/pg
```

## Схема пока может быть пустой

```ts
// src/db/schema.ts
export {};
```

## Подключение

```ts
// src/db/index.ts
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";
import { env } from "../config/env.js";
import * as schema from "./schema.js";

export const pool = new Pool({
  connectionString: env.DATABASE_URL,
  max: 10,
  idleTimeoutMillis: 30_000,
  connectionTimeoutMillis: 2_000,
});

export const db = drizzle({
  client: pool,
  schema,
});
```

Передача `schema` нужна для запросов вида `db.query.users.findMany()` со связями. Обычный построитель `db.select()` может работать и без неё.

## Проверка

```ts
import { sql } from "drizzle-orm";
import { db } from "./index.js";

const result = await db.execute(sql`SELECT 1 AS value`);
console.log(result.rows);
```

## Зачем передавать готовый пул

Так приложение управляет соединениями в одном месте:

- Drizzle использует общий пул;
- настройки не дублируются;
- пул можно закрыть через `pool.end()`;
- низкоуровневый запрос `pg` при необходимости использует тот же пул.

## Подключение без собственного пула

Drizzle умеет создать соединение из строки:

```ts
const db = drizzle(process.env.DATABASE_URL!);
```

Для учебного примера это короче. В Express-приложении явный `Pool` удобнее для настройки, наблюдения и корректной остановки.

## Что важно помнить

- `drizzle-orm` нужен во время работы приложения, `drizzle-kit` — только для разработки и миграций.
- Готовый пул `pg` передаётся в `drizzle()` — так его можно настроить и закрыть самостоятельно.
- Если Drizzle создаёт пул сам по строке соединения, закрывать его всё равно нужно при остановке.
- Схему передают в `drizzle()`, если планируется использовать API запросов со связями (`db.query`).

## Мини-шпаргалка

- `drizzle-orm` выполняет запросы.
- `drizzle-kit` управляет схемой и миграциями.
- Для PostgreSQL Drizzle может использовать `pg`.
- Один пул передаётся в `drizzle()`.
- Пул закрывается отдельно через `pool.end()`.
