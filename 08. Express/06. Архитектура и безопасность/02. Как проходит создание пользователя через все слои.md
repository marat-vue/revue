# Как проходит создание пользователя через все слои?

> [!NOTE]
> Цельный сценарий помогает увидеть границы: маршрут проверяет тело, контроллер выбирает HTTP-ответ, служба выполняет действие, репозиторий строит запрос Drizzle.

## Вопрос

Как запрос на создание пользователя проходит через все слои Express-приложения: от маршрута до Drizzle?

## Схема входа

```ts
// users.schema.ts
import { z } from "zod";

export const createUserSchema = z.object({
  name: z.string().trim().min(2).max(100),
  email: z.string().trim().email().toLowerCase(),
});

export type CreateUserInput = z.infer<typeof createUserSchema>;
```

## Репозиторий

```ts
// users.repository.ts
import { db } from "../../db/index.js";
import { users } from "../../db/schema.js";
import type { CreateUserInput } from "./users.schema.js";

export async function insertUser(input: CreateUserInput) {
  const [user] = await db
    .insert(users)
    .values(input)
    .returning();

  return user;
}
```

## Служба

```ts
// users.service.ts
import { AppError } from "../../errors/app-error.js";
import { insertUser } from "./users.repository.js";
import type { CreateUserInput } from "./users.schema.js";

function hasDatabaseCode(error: unknown): error is Error & { code: string } {
  return error instanceof Error && "code" in error;
}

export async function createUser(input: CreateUserInput) {
  try {
    const user = await insertUser(input);

    if (!user) {
      throw new Error("INSERT не вернул пользователя");
    }

    return user;
  } catch (error) {
    if (hasDatabaseCode(error) && error.code === "23505") {
      throw new AppError(
        409,
        "EMAIL_ALREADY_EXISTS",
        "Пользователь с такой почтой уже существует",
      );
    }

    throw error;
  }
}
```

## Контроллер

```ts
// users.controller.ts
import type { RequestHandler } from "express";
import { createUserSchema } from "./users.schema.js";
import * as usersService from "./users.service.js";

export const createUser: RequestHandler = async (request, response) => {
  const input = createUserSchema.parse(request.body);
  const user = await usersService.createUser(input);

  response
    .status(201)
    .location(`/api/users/${user.id}`)
    .json({ data: user });
};
```

## Маршрут

```ts
// users.routes.ts
import { Router } from "express";
import { createUser } from "./users.controller.js";

export const usersRouter = Router();

usersRouter.post("/", createUser);
```

## Что можно улучшить дальше

- преобразовать строку таблицы в безопасный DTO;
- вынести общую проверку тела в middleware;
- записывать идентификатор запроса;
- добавить тест службы и тест HTTP-маршрута.

## Что важно помнить

- Проверка тела через Zod происходит на границе HTTP — до контроллера.
- Служба выбрасывает прикладную ошибку (`EMAIL_TAKEN`), а не формирует HTTP-ответ.
- Контроллер выбирает статус `201` и формат ответа, репозиторий строит запрос Drizzle.
- Ошибка из любого слоя поднимается в общий обработчик Express 5 без `try/catch` в маршруте.

## Мини-шпаргалка

- Проверка входа происходит на границе HTTP.
- Репозиторий знает Drizzle.
- Служба знает прикладные ошибки.
- Контроллер знает HTTP-код и формат ответа.
- Ошибка поднимается в общий обработчик Express 5.
