# Как HTTP-запрос проходит через Express?

> [!NOTE]
> Express последовательно передаёт запрос через промежуточные обработчики, затем запускает подходящий маршрут и отправляет сформированный ответ клиенту.

## Вопрос

Как HTTP-запрос проходит через Express-приложение? Почему важен порядок регистрации обработчиков?

## Общая схема

```text
Клиент
  ↓
HTTP-сервер Node.js
  ↓
express.json()
  ↓
CORS, журнал, авторизация
  ↓
маршрутизатор
  ↓
обработчик маршрута
  ↓
служба и база данных
  ↓
JSON-ответ
```

## Пример цепочки

```ts
import express from "express";

const app = express();

app.use(express.json());

app.use((request, response, next) => {
  console.log(request.method, request.url);
  next();
});

app.post("/api/users", (request, response) => {
  response.status(201).json({
    id: 1,
    name: request.body.name,
  });
});
```

Для `POST /api/users` произойдёт следующее:

1. `express.json()` прочитает JSON и запишет его в `request.body`.
2. Следующая функция выведет метод и адрес.
3. `next()` передаст управление дальше.
4. Express найдёт подходящий маршрут.
5. Маршрут сформирует ответ с кодом `201`.

## Почему важен порядок

Express выполняет обработчики сверху вниз.

```ts
// Правильно: JSON разбирается до маршрута.
app.use(express.json());
app.post("/api/users", createUser);
```

```ts
// Неправильно: маршрут ещё не получил разобранное тело.
app.post("/api/users", createUser);
app.use(express.json());
```

Обработчик ошибки и маршрут `404` обычно размещают в самом конце.

## Запрос должен завершиться

Каждый путь выполнения должен сделать одно из двух:

- отправить ответ;
- вызвать `next()` и передать управление дальше.

```ts
app.use((request, response, next) => {
  if (!request.headers.authorization) {
    response.status(401).json({ message: "Требуется авторизация" });
    return;
  }

  next();
});
```

Если не отправить ответ и не вызвать `next()`, запрос зависнет.

## Что важно помнить

- Express вызывает функции строго в порядке `app.use()` и объявления маршрутов.
- Каждая ветка обработчика должна либо отправить ответ, либо вызвать `next()` — иначе запрос зависнет.
- `express.json()` регистрируется до маршрутов, иначе `request.body` будет пустым.
- Маршрут `404` и обработчик ошибок подключаются последними.

## Мини-шпаргалка

- Express обрабатывает функции по порядку регистрации.
- `next()` передаёт запрос следующей функции.
- Маршрут обычно завершает запрос ответом.
- Общие обработчики регистрируются до маршрутов.
- `404` и обработчик ошибок размещаются после маршрутов.
