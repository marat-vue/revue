# Как написать и запустить первый сервер?

> [!NOTE]
> Express-приложение создаётся вызовом `express()`. После объявления маршрутов метод `listen()` открывает порт и начинает принимать запросы.

## Вопрос

Как написать и запустить первый Express-сервер? Что делают `express.json()` и `listen()`?

## Основная идея

Создадим `src/server.ts`:

```ts
import "dotenv/config";
import express from "express";

const app = express();
const port = Number(process.env.PORT ?? 3000);

app.use(express.json({ limit: "100kb" }));

app.get("/api/health", (request, response) => {
  response.json({ status: "ok" });
});

app.get("/api/users/:id", (request, response) => {
  response.json({
    id: Number(request.params.id),
    name: "Анна",
  });
});

app.listen(port, () => {
  console.log(`Сервер запущен: http://localhost:${port}`);
});
```

## Запуск

```bash
npm run dev
```

Проверка в браузере:

```text
http://localhost:3000/api/health
```

Проверка через `curl`:

```bash
curl http://localhost:3000/api/users/42
```

Ответ:

```json
{
  "id": 42,
  "name": "Анна"
}
```

## Что делает `express.json()`

```ts
app.use(express.json({ limit: "100kb" }));
```

Этот обработчик читает запрос с `Content-Type: application/json` и записывает результат в `request.body`.

Ограничение размера защищает сервер от случайной или намеренной отправки слишком большого JSON.

## Что делает `listen()`

`listen()` создаёт HTTP-сервер Node.js и привязывает его к порту.

```ts
const server = app.listen(3000);
```

Возвращённый объект `server` понадобится для корректной остановки приложения.

## Частые проблемы

### Порт уже занят

```text
EADDRINUSE: address already in use
```

Останови старый процесс или выбери другой порт.

### `request.body` равен `undefined`

Убедись, что `express.json()` зарегистрирован до маршрута и клиент отправляет заголовок `Content-Type: application/json`.

### Изменения не появились

Запускай проект через `npm run dev`, чтобы `tsx watch` перезапускал процесс.

## Что важно помнить

- `express.json()` разбирает тело только при заголовке `Content-Type: application/json`.
- Лимит размера тела (`limit`) защищает сервер от слишком больших запросов.
- `listen()` возвращает объект `server` — он нужен для корректной остановки.
- Ошибка `EADDRINUSE` означает, что порт уже занят другим процессом.

## Мини-шпаргалка

- `express()` создаёт приложение.
- `app.use(express.json())` разбирает JSON.
- `app.get()` объявляет маршрут.
- `app.listen()` открывает порт.
- Проверить API можно браузером, `curl`, Postman или Playwright.
