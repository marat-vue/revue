# Как установить `pg` и подключиться к PostgreSQL?

> [!NOTE]
> Для обычного серверного приложения создают один пул `pg` на весь процесс и используют его во всех модулях работы с данными.

## Вопрос

Как установить `pg` и подключиться к PostgreSQL из Express? Почему пул создают один раз?

## Установка

```bash
npm install pg
npm install --save-dev @types/pg
```

## Создание пула

```ts
// src/db/pool.ts
import { Pool } from "pg";
import { env } from "../config/env.js";

export const pool = new Pool({
  connectionString: env.DATABASE_URL,
  max: 10,
  idleTimeoutMillis: 30_000,
  connectionTimeoutMillis: 2_000,
});

pool.on("error", (error) => {
  console.error("Ошибка свободного соединения PostgreSQL", error);
});
```

## Проверка соединения

```ts
const result = await pool.query<{ now: Date }>(
  "SELECT now() AS now",
);

console.log(result.rows[0]?.now);
```

Соединение открывается лениво при первом запросе.

## Проверка при запуске

Для небольшого приложения полезно убедиться, что база доступна до открытия HTTP-порта:

```ts
import { app } from "./app.js";
import { pool } from "./db/pool.js";

await pool.query("SELECT 1");

const server = app.listen(env.PORT, () => {
  console.log(`Сервер запущен на порту ${env.PORT}`);
});
```

Если база обязательна для всех маршрутов, быстрый отказ понятнее, чем работающий сервер, который возвращает `500` на каждый запрос.

## Не создавай пул в каждом запросе

```ts
// Плохо
app.get("/api/users", async (request, response) => {
  const pool = new Pool({ connectionString: env.DATABASE_URL });
  const result = await pool.query("SELECT * FROM users");
  response.json(result.rows);
});
```

Так быстро создаётся слишком много соединений. Пул должен быть общим для процесса.

## Закрытие

При остановке приложения:

```ts
await pool.end();
```

После `pool.end()` новые запросы выполнять нельзя.

## Что важно помнить

- Пул создаётся в отдельном модуле и импортируется репозиториями.
- `Pool` не открывает соединения заранее — они создаются при первых запросах.
- Проверочный `SELECT 1` при старте сразу показывает неверный `DATABASE_URL`.
- Пул в каждом HTTP-запросе быстро исчерпывает лимит соединений PostgreSQL.
- При остановке процесса вызывается `pool.end()`.

## Мини-шпаргалка

- Установи `pg` и `@types/pg`.
- Создай один `Pool` на процесс.
- Соединения открываются по необходимости.
- Проверь базу при запуске, если без неё сервер бесполезен.
- При остановке вызови `pool.end()`.
