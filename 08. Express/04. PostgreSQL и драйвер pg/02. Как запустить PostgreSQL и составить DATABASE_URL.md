# Как запустить PostgreSQL и составить `DATABASE_URL`?

> [!NOTE]
> Express подключается к уже запущенному PostgreSQL по строке соединения. Для локального обучения базу можно установить на компьютер или запустить в контейнере.

## Вопрос

Как запустить PostgreSQL для разработки и правильно составить `DATABASE_URL`?

## Строка соединения

```text
postgresql://app:password@localhost:5432/app_db
```

Она состоит из частей:

```text
postgresql://пользователь:пароль@сервер:порт/база
```

## Запуск через Docker Compose

```yaml
# compose.yml
services:
  postgres:
    image: postgres:18-alpine
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: password
      POSTGRES_DB: app_db
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app -d app_db"]
      interval: 5s
      timeout: 5s
      retries: 10

volumes:
  postgres_data:
```

Запуск:

```bash
docker compose up -d
docker compose ps
```

Остановка без удаления данных:

```bash
docker compose down
```

Команда с `-v` удалит и том с базой. Не используй её, если данные нужны.

## `.env`

```dotenv
DATABASE_URL=postgresql://app:password@localhost:5432/app_db
```

В настоящем окружении используй длинный случайный пароль и защищённое хранилище секретов.

## Проверка через `psql`

Если клиент `psql` установлен:

```bash
psql "postgresql://app:password@localhost:5432/app_db"
```

Простой запрос:

```sql
SELECT current_database(), current_user, now();
```

## Удалённая база

Облачный PostgreSQL часто требует TLS. Следуй настройкам своего поставщика и не отключай проверку сертификата только ради исчезновения ошибки.

## Что важно помнить

- Формат строки: `postgresql://пользователь:пароль@хост:порт/база`.
- Спецсимволы в пароле (`@`, `:`, `/`) нужно URL-кодировать.
- Внутри Docker Compose хост базы — имя сервиса (`db`), а не `localhost`.
- Данные контейнера сохраняются в volume, иначе пропадут при пересоздании.
- Удалённые базы часто требуют SSL — это настраивается в строке или в опциях пула.

## Мини-шпаргалка

- PostgreSQL должен быть запущен отдельно от Express.
- Стандартный порт PostgreSQL — `5432`.
- `DATABASE_URL` содержит пользователя, пароль, адрес и имя базы.
- Локальную базу удобно запускать контейнером.
- Пароль и строка соединения не отправляются в Git.
