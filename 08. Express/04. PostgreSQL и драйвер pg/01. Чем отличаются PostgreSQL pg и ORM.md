# Чем отличаются PostgreSQL, `pg` и ORM?

> [!NOTE]
> PostgreSQL хранит и обрабатывает данные, `pg` соединяет Node.js с PostgreSQL, а ORM помогает описывать таблицы и строить запросы средствами TypeScript.

## Вопрос

Чем отличаются PostgreSQL, драйвер `pg` и ORM? Какую задачу решает каждый уровень?

## Уровни

```text
Код Express
    ↓
Drizzle ORM
    ↓
драйвер pg
    ↓
PostgreSQL
```

## PostgreSQL

Это отдельный процесс базы данных. Он:

- хранит таблицы и строки;
- выполняет SQL;
- проверяет ограничения;
- управляет транзакциями;
- обеспечивает одновременную работу запросов;
- сохраняет данные независимо от перезапуска Express.

## Драйвер `pg`

Пакет также называют `node-postgres`. Он:

- открывает сетевые соединения;
- создаёт пул соединений;
- передаёт SQL и параметры;
- получает строки и сведения о результате;
- поддерживает транзакции на низком уровне.

```ts
const result = await pool.query(
  "SELECT id, name FROM users WHERE id = $1",
  [42],
);
```

## Drizzle ORM

Drizzle использует драйвер и добавляет:

- описание таблиц в TypeScript;
- вывод типов для чтения и записи;
- построитель SQL-запросов;
- миграции через Drizzle Kit;
- связи между таблицами;
- удобные транзакции.

```ts
const user = await db
  .select()
  .from(users)
  .where(eq(users.id, 42));
```

## Зачем изучать `pg`, если будет Drizzle

ORM не отменяет:

- соединения и пул;
- SQL и индексы;
- транзакции;
- ошибки PostgreSQL;
- ограничения таблиц;
- стоимость запросов.

При сложном запросе или ошибке производительности понимание нижнего уровня особенно важно.

## Что важно помнить

- PostgreSQL хранит данные и обеспечивает ограничения; `pg` и Drizzle данных не хранят.
- Drizzle использует `pg` как драйвер и строит SQL, который всё равно выполняет PostgreSQL.
- Знание `pg` помогает понять, что делает ORM, и отлаживать сгенерированные запросы.
- SQL нужен и с ORM: для индексов, `EXPLAIN` и сложных запросов.

## Мини-шпаргалка

- PostgreSQL — сама база данных.
- `pg` — драйвер Node.js для PostgreSQL.
- Drizzle — типизированный слой над драйвером и SQL.
- Drizzle не хранит данные сам.
- Знание SQL нужно даже при использовании ORM.
