# Как реализовать CRUD через `pg`?

> [!NOTE]
> Репозиторий скрывает SQL от остального приложения. Он получает типизированные значения и возвращает строки базы или `undefined`.

## Вопрос

Как реализовать CRUD через `pg` в виде репозитория? Что возвращают запросы, если строка не найдена?

## Тип строки

```ts
export type UserRow = {
  id: number;
  name: string;
  email: string;
  created_at: Date;
};
```

Имя `created_at` совпадает с именем столбца. Позже DTO преобразует его в `createdAt`.

## Получение списка

```ts
export async function findUsers(limit: number, offset: number) {
  const result = await pool.query<UserRow>(
    `
      SELECT id, name, email, created_at
      FROM users
      ORDER BY id
      LIMIT $1 OFFSET $2
    `,
    [limit, offset],
  );

  return result.rows;
}
```

## Получение одного

```ts
export async function findUserById(id: number) {
  const result = await pool.query<UserRow>(
    `
      SELECT id, name, email, created_at
      FROM users
      WHERE id = $1
    `,
    [id],
  );

  return result.rows[0];
}
```

## Создание

```ts
type CreateUser = {
  name: string;
  email: string;
};

export async function insertUser(input: CreateUser) {
  const result = await pool.query<UserRow>(
    `
      INSERT INTO users (name, email)
      VALUES ($1, $2)
      RETURNING id, name, email, created_at
    `,
    [input.name, input.email],
  );

  return result.rows[0];
}
```

## Изменение

```ts
export async function updateUserName(id: number, name: string) {
  const result = await pool.query<UserRow>(
    `
      UPDATE users
      SET name = $2
      WHERE id = $1
      RETURNING id, name, email, created_at
    `,
    [id, name],
  );

  return result.rows[0];
}
```

## Удаление

```ts
export async function removeUser(id: number): Promise<boolean> {
  const result = await pool.query(
    "DELETE FROM users WHERE id = $1",
    [id],
  );

  return result.rowCount === 1;
}
```

## Маршрут использует репозиторий

```ts
app.get("/api/users/:id", async (request, response) => {
  const { id } = idParamsSchema.parse(request.params);
  const user = await findUserById(id);

  if (!user) {
    throw new AppError(404, "USER_NOT_FOUND", "Пользователь не найден");
  }

  response.json({ data: toUserResponse(user) });
});
```

## Что важно помнить

- Репозиторий скрывает SQL: остальной код работает с функциями `findById`, `create`, `update`.
- Тип строки задаётся дженериком `pool.query<UserRow>()` — это описание, а не проверка.
- `rows[0]` равен `undefined`, если запись не найдена — маршрут превращает это в `404`.
- `RETURNING *` возвращает созданную или изменённую строку без отдельного `SELECT`.
- `rowCount` показывает, удалено ли что-нибудь.

## Мини-шпаргалка

- SQL удобно хранить в репозитории.
- Тип строки отражает результат запроса.
- `rows[0]` равен `undefined`, если строка не найдена.
- `RETURNING` экономит дополнительный `SELECT`.
- `rowCount` показывает число затронутых строк.
